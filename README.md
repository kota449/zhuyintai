# 注音台 ZhuyinTai（Beta）

macOS 上的注音輸入法，給打繁體中文（台灣）的人。

**免費 Beta。** 我們正在量它和內建注音的差別，你的回報決定方向。

> 目前是 `v0.1.0-beta.1`。只有 Mac 版；需要 **macOS 14 以上、Apple Silicon（M1 以後）** 的 Mac。

## 它做什麼

- **整句輸入**：連續打注音，整句一起組字，按 Enter 送出。
- **候選字**：按 ↓ 開候選窗，用選字鍵挑字，候選多時可以翻頁。
- **打錯注音時，比較常幫你救回來。**
- **記住你的選字**：你在候選窗改選過的字，下次同樣的前文與讀音會優先給你（可關、可清除，只存在你的 Mac）。
- **詞庫頁最上面有查詞框**：打一個詞，就知道它是「已經內建」、「要開哪個詞庫包」，還是「都沒有，可以直接加進我的自訂詞」。
- **自訂詞**：把自己常用的詞加進去（在偏好設定的「詞庫」頁最下面）。
- **詞庫包**：「網路用語」預設開啟；另有「理工與資訊」「生命與地球」「人文社會藝術」三包，預設不開，要的時候自己勾選，加入該領域的詞。
- **注音浮窗**：打字時在游標下方顯示前三個字的注音，方便看出是不是自己拼錯（可關）。
- **單押 Shift 切換中／英**（可關）。切到英文時，游標旁會一直顯示一個小「英」，切回中文才消失，不會沒發現自己在英文模式。
- **沒拼完的注音**：按 Enter、切到英文或切換 App 時，最後一段還沒拼成字的注音要怎麼處理，可以在設定裡選。
- 偏好設定視窗（固定大小）：輸入、按鍵、詞庫、隱私、關於。詞庫頁由上到下是查詞框、詞庫包、我的自訂詞。
- 從選單按「結束」會先問一次，也可以選只關閉設定視窗。

## 和其他開源注音輸入法比

我們用同一批 15,000 句（取自 PTT 文章，和訓練資料零重疊）讓每個輸入法逐句組字，算「整句一次就全對」的比例：

| 輸入法 | 整句全對 |
|---|---|
| 注音台 | 73.2% |
| 小麥注音 3.1.1 | 60.4% |
| 威注音 4.8.1 | 60.4% |

注音台多對約 12.8 個百分點，也就是每 100 句多對約 13 句。

另一份書籍語料（300 句）：注音台 80.7%、小麥注音 73.3%、威注音 73.7%，注音台多對約 7 個百分點。

**量法**：2026 年 9 月量。三個輸入法都繞過畫面，直接呼叫各自的組字引擎，各自使用出廠的詞庫與排序；整句完全相同才算對。量的是注音打對的情況。

**致謝**：注音台使用了小麥注音的詞庫資料（MIT 授權），以及威注音的候選窗與組字引擎程式碼。感謝這兩個專案。

## 下載與安裝

1. 到 [Releases 頁](https://github.com/kota449/zhuyintai/releases) 下載最新的 `ZhuyinTai-<版本>.pkg`。
2. 雙擊安裝。
3. 安裝完成後，到「系統設定 → 鍵盤 → 輸入方式」按「＋」，把「注音台」加進去。**這一步安裝程式沒辦法代勞。**

詳細步驟與常見問題：[安裝說明](docs/INSTALL.md)。要移除：[解除安裝](docs/UNINSTALL.md)。

## 隱私

- 為了找出打字哪裡不順，注音台**預設會把打字過程記在你的 Mac 上**（預設開、不會跳出視窗問你）。
- 記錄**只存在你自己的 Mac**、**只保留約一週**，不會自己送到任何地方。要不要把檔案交給我們，由你決定。
- 不想記錄：偏好設定 →「隱私」把「記錄打字過程」關掉就好，隨時可以關。
- 注音台**只會連線檢查有沒有新版**，不會傳送你打的任何字；可以在「偏好設定 → 關於」關掉自動檢查。

完整說明：[隱私說明](docs/PRIVACY.md)。
