# 怎麼回報

Beta 的意義就是你的回報。**哪裡打得不順、哪個字排錯了、哪個詞找不到、哪裡不好用**，都請告訴我們。

## 回報管道

到這個 repo 的 [Issues](https://github.com/kota449/zhuyintai/issues) 開一則新的，選「回報問題或打字不順」，照範本填就好。

⚠️ **Issues 是公開的**——任何人都看得到。**請不要貼私人的打字內容**（對話、帳號、密碼、住址、公司資料）。
只貼那一個詞或那一句，用中性的例句就好。

**之後會再補**：回報表單、專用信箱。（目前只有 Issues。）

## 回報時請附上

1. **你打的注音**，照按鍵順序，例如 ㄒㄧˋ ㄌㄧˋ。
2. **你想要的字或詞**，以及**實際出現什麼**（候選第三個才出現？出現別的字？完全沒有？）。
3. **在哪個 App 打的**（備忘錄、Safari、Chrome、VS Code…）——有些 App 的行為不一樣。
4. **版本資訊**：偏好設定 →「關於」→ 按「回報問題」，會在瀏覽器直接打開回報表單，並在「版本資訊」欄預填「注音台版本＋macOS 版本」
   （同時也複製一份到剪貼簿；網頁沒預填成功就直接貼上）。
   「關於」畫面上會顯示版本與 build 號（括號裡的數字，每個 Beta 都不同），一起貼上即可。
5. 你的 Mac 是不是 Apple Silicon。

## 附診斷包（beta.2 起）

打不出字、切不回中文、反應變慢這類問題，除了上面的描述，可以再附一份診斷包：

1. 先把問題重現一次（診斷包預設只有最近 1 小時）。
2. 偏好設定 →「關於」→「產生診斷包…」。
3. 在畫面上看過內容（裡面**不含你打的字**），沒問題再按「存成檔案…」。
4. 在 Issue 裡說明「我有診斷包」，我們會回覆私下收件的方式。**檔案本身請不要附在公開的 Issues 上。**

診斷包只是輔助。你的描述（打了什麼注音、想要什麼字、實際出現什麼）還是最重要的。

## 請不要貼

- 密碼、帳號、身分證字號、銀行資料。
- 還沒看過內容的「匯出 log」檔。匯出的記錄檔裡有你打的字，**不要貼到公開的 Issues**。
- 診斷包也不要貼到公開的 Issues（走上面說的收件方式）。
