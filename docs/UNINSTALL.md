# 解除安裝

## 步驟

1. 先把輸入法切回別的（例如內建注音）。
2. 到「系統設定 → 鍵盤 → 輸入方式」，選「注音台」，按「−」移除。
3. 刪掉輸入法本體：打開 Finder，按 ⇧⌘G，貼上 `~/Library/Input Methods`，把 `TWKeyboard.app` 丟進垃圾桶。
4. 登出再登入一次（或重新開機），讓系統放掉它。

## 你的資料在哪、要不要刪

解除安裝**不會**刪你的資料。資料都在這個資料夾裡：

```
~/Library/Containers/com.kota.xrich.inputmethod.TWKeyboard/
```

裡面有你的自訂詞、選字記憶，以及打字記錄（預設開啟，只保留約一週；在「隱私」關掉後就不再記）。
要徹底清掉，把整個資料夾丟進垃圾桶即可。**這個動作無法復原。**

如果 Finder 說有項目「已鎖定」（打字記錄的封存檔會上鎖，避免被清理工具誤清），先到偏好設定 →「隱私」→「清除使用紀錄」，再把資料夾丟進垃圾桶。

只想清掉記錄、不想解除安裝：偏好設定 →「隱私」→「清除使用紀錄」；選字記憶也在同一頁可以清除。
