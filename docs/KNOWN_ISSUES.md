# 已知問題

> `v0.1.0-beta.1`。這是 Beta，下面是我們已經知道、還沒解決的事，以及一些「設計如此」、不是故障的行為。
> 有沒有列在這裡的問題，歡迎依 [回報方式](FEEDBACK.md) 告訴我們。

## 還沒解決的問題

- **有些詞的候選順序不理想，有些詞還找不到。** 同音字很多，常用的字詞有時會排在後面，偶爾也會有少見的詞排在前面。
  遇到的話請回報，附上你打的注音與你想要的字詞，我們會當成排序調整的依據。
- **同音的網路用語與日常詞，有少數組合候選順序還不理想**（例如檔期／當期），會在之後的版本調整。
- **省略聲調時偶爾會選錯同音字**：例如「不是真的」的「是」不打聲調，可能送出「不失真的」。打上聲調就不會發生。
- **游標旁的「英」提示，在部分 App 有時不會出現**：例如文字編輯、指令碼編寫程式，游標停在文件最後面的時候。這時輸入法其實已經在英文模式，照常打英文就好；要回中文，單押一下 Shift 就會切回來。
- **「記住我的選字」開關**：打開或關掉之後，要等到下一次切換輸入框（換到別的輸入欄位）才會生效。

## 設計如此／系統限制

這些不是故障，列出來讓你知道為什麼會這樣。

- **打字中用滑鼠點到別處**：最後一段還沒拼完的注音一律保留，不會被自動轉成字（這個行為不受「沒拼完的注音」設定影響）。
- **用 Caps Lock 切換中／英**：切走的當下，正在組字的內容會直接送出，不會不見。
- **「網路用語」詞庫包預設開啟**：如果覺得多出了不想要的候選，到「偏好設定 → 詞庫」關掉即可。
- **打字記錄預設開啟，且不會跳出視窗問你**：只存在你的 Mac、只保留約一週、不會自己送出；不想記錄請到「偏好設定 → 隱私」關掉（見 [隱私說明](PRIVACY.md)）。
- **只支援 Apple Silicon（M1 以後）、macOS 14 以上。**
- **安裝後要自己到「系統設定 → 鍵盤 → 輸入方式」把「注音台」加進去**，安裝程式做不到這一步。
- **更新後選單列可能找不到輸入法**：到「輸入方式」把「注音台」移除再加入一次。
- **從選單按「結束」之後**，下次切到注音台打字時，系統通常會自動重新啟動它，第一個字會稍慢（約 0.4 秒）。
