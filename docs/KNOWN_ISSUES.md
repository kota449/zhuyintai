# 已知問題

> `v0.1.0-beta.2`。這是 Beta，下面是還在改的地方，以及一些「設計如此」、不是故障的行為。
> 遇到沒列在這裡的問題，歡迎依 [回報方式](FEEDBACK.md) 告訴我們。

## 還在改的

- 候選字詞與排序持續優化中。
- 切到英文時，有些 App（例如部分瀏覽器、郵件程式、系統視窗）抓不到游標位置，游標旁的「英」提示可能不出現。beta.2 已在抓不到時改放文字開頭附近，但實測仍有不少次切換抓不到位置，還沒完全解決。
- 打錯字自動修正是 Beta 功能，beta.2 預設為關閉，要到「偏好設定 → 輸入」開啟「打錯字自動修正（Beta）」；關著的時候，按到隔壁的鍵、聲調打錯，都不會被自動救回，只能從候選窗自己挑。唯一的例外：沒打聲調就直接接著打下一個字，而且你打的那個讀音在詞庫裡查不到任何字（例如 ㄋㄧ），才會補查聲調（ㄋㄧㄏㄠˇ 仍是「你好」）；讀音查得到字時一律照你打的音，不會改。打開時，常用詞（例：那裡、照樣）打對了也不會被改成別的詞；按空白或 Enter 收尾的音一律當作一聲，不會再被猜成其他聲調，所以用空白代替聲調的打法不會被救回。

## 設計如此／系統限制

- 打字中用滑鼠點到別處，還沒拼完的注音會保留。
- 用 Caps Lock 切換中／英時，正在組的字會直接送出。
- 「網路用語」詞庫包預設開啟，不想要可以到「偏好設定 → 詞庫」關掉。
- 打字記錄預設開啟，只存在你的 Mac、約一週後刪除、不會送出；可以到「偏好設定 → 隱私」關掉（見 [隱私說明](PRIVACY.md)）。
- 只支援 Apple Silicon（M1 以後）、macOS 14 以上。
- 安裝後要自己到「系統設定 → 鍵盤 → 輸入方式」把「注音台」加進去；更新後若選單列找不到，移除再加入一次。
