# 安裝說明

## 需求

- **macOS 14 以上。**
- **Apple Silicon 的 Mac（M1 以後）。** Intel Mac 這個版本不支援。
  不確定自己的 Mac 是哪種：左上角  → 關於這台 Mac，看「晶片」那一行是不是「Apple M…」。

## 安裝

1. 下載最新的 `ZhuyinTai-<版本>.pkg`（[Releases 頁](https://github.com/kota449/zhuyintai/releases)）。
2. 雙擊 `.pkg`，照安裝程式的畫面一路按下去。安裝程式只會把注音台裝在**你自己的使用者資料夾**，不會動到系統。
3. 安裝完成後的最後一步要**自己動手**：

   「系統設定 → 鍵盤 → 輸入方式」→ 按「＋」→ 在清單裡找到「注音台」→ 加入。

   （安裝程式沒辦法替你把輸入法加進清單，這是 macOS 的限制。）
4. 用選單列的輸入法圖示切換到「注音台」，開始打字。

偏好設定：切到注音台之後，點選單列的輸入法圖示 →「偏好設定…」。
第一次打開可以順便看一下兩個地方：「詞庫」分頁（最上面是查詞框，接著是詞庫包——「網路用語」和 6 大類 30 小類的專業詞庫預設全部開啟，用不到的可以逐一關掉——最下面是我的自訂詞）、「隱私」分頁（打字記錄的開關）。

## 打字記錄（預設開啟）

為了找出打字哪裡不順，注音台**預設會把打字過程記在你的 Mac 上**，**安裝後不會跳出視窗問你**，所以先在這裡說明：

- 會記：你按的鍵、候選字、最後打出來的字，以及時間和你正在用的 App 名稱；密碼欄位不記。
- **只存在你自己的 Mac、只保留約一週、不會自己送到任何地方。**
- 想關掉：偏好設定 →「隱私」→ 關掉「記錄打字過程」，隨時可以。
- 細節見 [隱私說明](PRIVACY.md)。

## 更新

下載新版的 `.pkg`，同樣雙擊安裝，會原地覆蓋舊版，你的設定與自訂詞會保留。
更新後如果選單列找不到輸入法，到「系統設定 → 鍵盤 → 輸入方式」把「注音台」移除再重新加入一次。

## 裝好之後沒有出現「注音台」？

- 可以先試著登出再登入一次，再看一次「輸入方式」清單。
- 還是沒有：請依 [回報方式](FEEDBACK.md) 告訴我們你的 macOS 版本與晶片種類。
